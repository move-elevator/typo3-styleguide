# Icon fixtures

Sample directory for `FileListUtilityTest`.

The file names are deliberately mixed so the exclude patterns can be exercised:

- `icon-*.svg` — regular icons
- `*-alt.svg` — an icon variant
- `legacy-*.svg` — an icon that a styleguide would typically hide
- `sprite.json`, `README.md` — non-icon files that live next to the icons
- `subdir/` — must never show up, directories are not listed
